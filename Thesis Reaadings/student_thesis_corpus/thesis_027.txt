whole process has three modules: IMM(Image

Matting Module), LEM(Light Estimation Module)

and RM(Rendering Module). First, after the user

uploads the image, the input image obtains

the foreground image through IMM; Secondly,

through the illumination estimation of the input

image environment, the illumination parameters

in the scene are obtained through LEM; Then

use the foreground image information to replace

the material, and add a light source to the input

3D scene to simulate the original light source in

the Input Image to increase the authenticity of

the image. The original light source in the scene

remains unchanged, and finally a high-quality

rendered image is obtained through RM.

The three modules in the whole process are IMM(Image Matting Module), LEM(Light Estimation Module), and

RM(Rendering Module). The image matting module is a method of image segmentation, which is to accurately extract

the foreground and background of a given image. It is the first step of the whole process. The module is based on

the color, gradient, and structure information in the image to obtain the foreground and background. Light Estimation

Module is a module that uses the color and gradient information in the image to estimate the lighting parameters of

the environment. The lighting parameters include the color temperature, the ambient light intensity, and the direction

of the dominant light. It computes the lighting parameters of the environment from the image captured by the camera

and uses the computed lighting parameters to produce an enhanced image. The RM module renders a realistic image

by using existing 3D software in the market like Cinema 4D, Maya, Blender, and rendering engines like Octane, Redshift,

To experience the whole Dxpos procedure. First, users need to upload their images, the input image obtains the

In order to test the feasibility of the above modules, the

primary task of this project is to introduce new automation

functions through python scripts on the modeling software,

realize automatic rendering of input images, and realize the

operation of the RM module. The project selected Cinema

4D as the experimental platform and the Octane R engine

for rendering. Both applications have mature markets and

are widely used by designers and photographers in the field

of fashion virtual photography. After loading the written

python script into cinema 4D, the program performs well.

The processed input images dataset can be automatically

synthesized and stored in another file locally.

The next goal is to implement the first IMM module. This

module is mainly based on image segmentation technology,

which has mature API available in the market. This project

selects the removebg function of Kaleido Company. By

calling the API tool provided by the company, it can quickly

realize the precise cutting of portrait and background.

The LEM module is a technical difficulty of the project and

requires subsequent data training, which is not the focus

of this design. However, the overall technical route has

been proven feasible, so DxPOS will focus on the product

experience under this premise.

Discussion

In the metaverse, people always seem to like to discuss digital products such as digital clothing, virtual people, etc., but

ignore the energy contained in 3D art as an architectural unit that carries elements of the metaverse world. At the same

time, people always pay more attention to the innovation of digital assets and 3D technology under web3, including

AR and VR, but ignore the progress in application and practice of our proud image processing technology. We may

be confused by the concept of metaverse and enter a false world full of illusions. We should pay more attention to

the underlying design logic and create a sustainable ecosphere for the 3D world for the stakeholders including users,

creators, artists, application software, etc.

In the future, the DxPOS system can be used for other purposes in the photography business. For example, it can be

mixed and matched with other projection technologies for CG blockbuster and green screen synthesis. DxPOS is also

working on a new content production with a team of artists, which is still in the concept stage.

Furthermore, according to the development direction of DxPOS, I also hope to build a digital community dedicated to 3D

artists, integrating a complete set of application processes including digital design resources, user scene synthesis, and

enterprise cooperation. On this platform, 3D artists will be encouraged to upload their 3D work, and users will have the

opportunity to composite themselves into these great works.
